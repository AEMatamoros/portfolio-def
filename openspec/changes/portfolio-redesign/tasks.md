## Conventions for apply

- One commit per group, message exactly as the group title (Conventional Commits, no AI attribution). Husky runs lint-staged and commitlint. Commit body records the Gate result, the focused command result, and the rollback boundary.
- Every unit ends with `pnpm check` and `pnpm build` green. From unit 1 on, new imports use `@/...` only (the other aliases disappear in unit 6).
- Before unit 8, add i18n strings in the existing flat style in `src/i18n/EN.ts` and `ES.ts`. From unit 8, add them to the typed `locales/{en,es}.ts`. Existing Spanish copy never changes; only new keys are added. [localization: Copy change scope]
- Lint findings introduced by unit 5 inside a file that a later unit rebuilds may take one `// eslint-disable-next-line <rule> -- rebuilt in unit N` line. The final group greps for that sentinel and it must return nothing.
- Defects found later in the matrix: `git commit --fixup <unit commit>` then `git rebase -i --autosquash` before the PR is opened, to keep one commit per unit.
